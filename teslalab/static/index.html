SERVER-ENFORCED PERMISSIONS
Live diagnostic access
LOCKED
Passive receive needs no transmit permission. Live read requests require the host flag, a verified physical ECU pair, and fresh live bus-0 Park + two stationary speed signals.
Freshness expires at 0.5 s. A missing signal, transport fault or expired attestation disarms transmit. Demo and replay cannot satisfy live interlocks.
GUARDED WRITES
Clearing requires evidence and intent
Live DTC clear requires an ECU-specific verified-clear profile, host write permission, a recent saved scan, and a 30-second single-use confirmation tied to that ECU and acquisition.
EAS clear uses standard UDS bytes but is unverified on this ECU. It is disabled live. You can exercise the complete confirmation flow in demo.
No enabled movement actions
Operating boundaries
The server binds only to this computer. Browser requests are checked for local host, session and origin. Manufacturer routines, session changes and calibration writes stay inspection-only. There is no automatic hardware recovery routine, guessed command, or diagnostic retry after an ambiguous timeout.
Car-off state is an operator attestation, not a verified telemetry signal. Firmware and supplied DBC applicability require vehicle validation before active use. Hardware has not been tested by this build.
